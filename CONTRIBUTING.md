# Contributing to PlayStash documentation

Read [AGENTS.md](AGENTS.md), verify the relevant implementation and update
[CHANGELOG.md](CHANGELOG.md) for reader-facing changes. Keep routes stable where
possible and run the declared checks and production website build.

Preserve original attribution and notices. Contributions use the repository's
existing [CC BY-NC-SA 4.0 license](LICENSE).
Do not commit credentials or unverified installation claims.
