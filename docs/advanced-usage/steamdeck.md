# Steam Deck

Use the Linux x64 cross-platform AppImage on a compatible desktop environment.
Connect to your normal frontend URL. Download the public AppImage from
[frontend releases](https://github.com/PlayStash/playstash-frontend/releases)
without GitHub sign-in.

Big Picture provides controller navigation. Windows-game support depends on the
local Wine/Proton environment and game. The server supplies files and metadata
rather than configuring your device's operating system.

No current device-specific installer script or universal compatibility result is
provided. Follow [Linux setup](linux-client.md) and inspect desktop launch logs.
